# Element card images

Upload element card images here (GitHub website: **Add file → Upload files**). Any size, JPG or PNG.

**Name each file so it says which element it is**, best with the atomic number:
`47.jpg`, `13.png`, `001-hydrogen.jpg` (a symbol like `Ag.jpg` or a name like `Silver.png` also works).

A GitHub Action converts them to light WebP cards (`../cards/`) and updates `../cards.json` within a
minute or two; the app shows the new card the next time it is opened. To fix a card, upload a new image
with the same name; to remove one, delete its image here.
